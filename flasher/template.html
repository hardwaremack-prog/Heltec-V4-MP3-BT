Heltec V4 MP3

Expanded music player for the Heltec WiFi LoRa 32 V4 · MP3 / AAC / FLAC / WAV · internet radio · EQ · sleep timer · battery gauge · Bluetooth headset · Wi-Fi control panel
firmware v__VERSION__ ESP32-S3R2 · 2 MB PSRAM · 16 MB flash __SIZE__ KB works offline

1 · Flash the board

  1. Plug the Heltec V4 into this computer with a USB-C data cable.
  2. Click Connect & Flash and pick the USB JTAG/serial debug unit port (the V4 uses the chip's own USB).
  3. Wait for 100 %. The board reboots into the player.
Ready.

Won't connect, or no port shows up? Hold PRG, tap RST, let go of PRG, then try again. If the port disappears after flashing, unplug and replug the board. Close Arduino IDE and serial monitors first. Only for the standard V4 (ESP32-S3R2). The V4-R8 variant has a different pin map.

3 · Wiring

V4 pin notes: GPIO 2, 5, 7 and 46 run the V4's LoRa power amplifier, 19/20 are USB and 26 is PSRAM, so leave those alone. The SD card shares GPIO 39–42 with the GNSS connector, so don't plug in the GNSS kit. The battery gauge uses the V4's built-in sensing (GPIO 1 + 37) and needs no wiring.

4 · Bluetooth headset

The Heltec V4's ESP32-S3 chip only has Bluetooth Low Energy. Headsets stream music over Classic Bluetooth (A2DP), which the S3 doesn't have, so the board can't pair with a headset by itself. A KCX_BT_EMITTER transmitter module (a few dollars, V1.7 recommended) does the headset part. The player controls it over two serial wires, so you can scan, connect and forget headsets from the OLED or the web page.

Level shifter: a 4-channel BSS138 board. LV = 3V3, HV = 5V, GND to GND. On the V4 the header's TX/RX pins (43/44) are free because USB goes straight to the chip. The KCX expects 5 V serial signals, and some people report problems running it straight from 3.3 V pins.

  • OLED: Home → Bluetooth → Scan for headsets. Headsets show up as they're found. Select one to connect. * means it's remembered.
  • Web page: the Bluetooth tab has scan, Connect buttons, the remembered list, "Forget all" and a raw command console.
  • Put the headset in pairing mode before you scan.
  • It remembers up to 10 headsets and auto-connects to the first one it sees. With none saved, it connects to any headset in pairing mode.
  • The 5V pin only has power on USB. For battery or solar use, add a small 5 V boost board for the module.
  • Wired headphones in the DAC's jack still work, but Bluetooth audio lags slightly behind them.

5 · Wi-Fi control panel

  1. First boot: the player makes its own hotspot Heltec-MP3-XXXX, password heltecmp3.
  2. Join it with your phone. The control page pops up, or go to 192.168.4.1.
  3. Wi-Fi tab → Scan → pick your home network → enter the password → Save & restart.
  4. After that, open the IP shown on the OLED (Home → Wi-Fi) or http://heltec-mp3.local from any device on your network.

If home Wi-Fi is down, it opens the hotspot again after 15 s and keeps retrying. You can turn Wi-Fi off in Home → Wi-Fi to save battery.

  • Player: play / pause / skip, volume, play mode, shuffle all, EQ, sleep timer.
  • Library: search the whole card, browse, tap to play, upload music, new folder, delete.
  • Radio: play, add, reorder and delete stations.
  • Bluetooth: scan, connect, remember and forget headsets.
  • Wi-Fi: join or forget networks.
  • System: PSRAM, battery and SD space, restart, and wireless firmware updates (use the heltec-v4-mp3-app .bin).

V4 extras

  • More formats: MP3, AAC (.aac), FLAC and WAV, with 64 KB read-ahead buffers in PSRAM.
  • Internet radio: Home → Internet radio, or the web page's Radio tab. Live song titles, 128 KB buffer, automatic reconnect. You can add your own http:// streams.
  • Big libraries: 2000 items per folder, Shuffle all music across up to 5000 songs, and whole-card search on the web page.
  • EQ: bass and treble ±6 dB, from Settings or the web sliders, with presets.
  • Sleep timer: 15–90 min, fades out over the last 15 s.
  • VU meter on Now Playing and a battery gauge in the header and on the web page.
  • Lower power: the LoRa amplifier stays switched off.

6 · SD card

  • Format as FAT32 (cards up to 32 GB are easiest).
  • Copy .mp3, .aac, .flac or .wav files in, or upload them over Wi-Fi from the Library tab. Folders are fine (Artist / Album).
  • Up to 2000 items per folder. Folders show first, A→Z.
  • The title and artist come from the MP3's ID3 tags, or the file name if it has none.
  • No card at boot? The player shows the wiring pins. Fix it and press OK (or hold PRG) to retry.

7 · Menus

  • Browse music: walk folders and pick a song. The rest of that folder becomes the playlist.
  • Now playing: shows title, artist, a progress bar, time and track number.
  • Resume last: picks up the last song after a reboot.
  • Internet radio: your station list. Needs home Wi-Fi.
  • Shuffle folder / Shuffle all music: the folder you're in, or the whole card.
  • Bluetooth: headset status, scan, connect, reconnect, forget.
  • Wi-Fi: on/off, IP address, network or hotspot name and password.
  • Settings: volume, mode (Normal / Repeat all / Repeat one / Shuffle), screen timeout, brightness, resume, re-scan SD card, bass, treble, sleep timer, visualizer.

Settings are saved on the board and kept between power-ups.
